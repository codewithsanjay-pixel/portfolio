Project. American Airlines. Employer work, described in general terms.

Enterprise Knowledge Assistant

The problem

Employees needed one place to ask questions about internal documentation, policies and system data.

How it fits together

Retrieval
A retrieval pipeline over internal documents using pgvector.
Agent layer
An agent that could take follow-up actions, such as opening tickets and pulling live data, through tool calling.
MCP server
A custom MCP server that exposed internal APIs and databases as standard, secure context sources, so other internal AI tools could reuse them.
Frontend
A React frontend for employees and admin monitoring.
